# 타일 재료과학·제조공정·국제규격 심화 학습 1차

- **조사일:** 2026-07-27
- **범위:** 세라믹/포세린/도기질/자기질/석기질, 습식·건식 원료조제, 성형·소성·유약·디지털 프린팅·폴리싱·래티파이드, 흡수율·파괴강도·마모·내화학·동결·미끄럼
- **중심 규격:** ISO 13006:2018, BS EN/EN 14411:2016, ISO 10545 시리즈, ANSI A137.1(판본은 계약서에 명시)
- **중요 한계:** 표준 원문은 대체로 유료이다. 아래 수치·판정은 공식 표준 카탈로그/공개 초록과 협회·제조 기술자료를 우선해 요약했다. 실제 적합성 판정·입찰·분쟁에는 구매한 **해당 판본 원문과 시험성적서**를 적용해야 한다.

## 1. 한 장으로 보는 핵심 모델

1. **세라믹 타일**은 상위 개념이다. 포세린도 세라믹 타일이다. `세라믹 vs 포세린`을 서로 배타적인 두 재료로 쓰는 판매 문구는 분류축이 잘못되었다.
2. ISO 13006/EN 14411의 핵심 분류축은 **성형법**과 **흡수율 E**이다.  
   - A = 압출(extruded), B = 건식 프레스(dry-pressed), C = 기타
   - Ia: E ≤ 0.5%, Ib: 0.5% < E ≤ 3%, IIa: 3% < E ≤ 6%, IIb: 6% < E ≤ 10%, III: E > 10%
3. **포세린(porcelain tile)**의 규격상 핵심은 보통 `E ≤ 0.5%`의 충분히 치밀화된 타일이다. 가장 흔한 포세린은 **BIa**지만 압출 **AIa**도 정의상 가능하다. 포세린은 `백색`, `무유`, `통바디`, `폴리싱`, `래티파이드`를 뜻하지 않는다.
4. 한국 현장의 **도기질/석기질/자기질**은 역사적 소지·소성 개념과 흡수율 구간을 섞어 쓴다. 따라서 명칭만으로 ISO 그룹을 확정하지 말고 **ISO 그룹 + 시험 흡수율 + 성형법**을 함께 저장한다.
5. **습식/건식 공정**은 원료조제법, **유광/무광/폴리싱**은 표면·가공, **래티파이드**는 모서리 치수 가공, **미끄럼 저항**은 시험 성능이다. 네 축은 독립이다.
6. `PEI`, `Mohs`, `DCOF`, `R`, `PTV`는 서로 다른 시험이다. 수치나 등급을 상호 환산하지 않는다.

근거: ISO 13006 공식 제목·범위 [S1, A], ISO 10545-3의 분류용 흡수율 시험 범위 [S2, A], EN 14411 공식 회원기관 카탈로그 [S9, A].

## 2. 재료 용어와 한국 현장 매핑

### 2.1 재료과학적 구분

| 용어 | 기술적 의미 | 전형적 조직/제조 | ISO/EN에 넣는 안전한 방법 | 한국 현장 해석 |
|---|---|---|---|---|
| **ceramic tile / 세라믹 타일** | 점토 및 기타 무기 원료를 성형·건조·소성한 타일의 상위 범주 | 다공질부터 유리화된 치밀질까지 모두 포함 | `material_family=ceramic`; 별도로 forming/group/E 기록 | 국내에서 종종 도기질 벽타일만 “세라믹”이라 부르나 국제 분류와 다름 |
| **porcelain tile / 포세린 타일** | 높은 치밀화·유리화로 규격 흡수율 E ≤ 0.5%인 세라믹 타일 | 점토/고령토·장석계 융제·석영 등의 소지, 고온 소성; 실제 조성은 업체별 상이 | `AIa 또는 BIa`와 실제 E를 확인 | 대형 무광 바닥타일의 상업명으로 자주 쓰지만 유광·유약·압출 포세린도 가능 |
| **earthenware / 도기질** | 상대적으로 다공질이며 완전 유리화되지 않은 저흡착도 아닌 소지; 표면 기능을 위해 유약을 쓰는 경우가 많음 | 낮은 치밀화, 높은 개기공 | 흔히 BIII(E>10%)에 대응하지만 **명칭만으로 확정 금지** | 실내 벽타일 의미로 널리 사용; 바닥/동결부 사용 여부는 별도 성능 확인 |
| **stoneware / 석기질** | 도기질보다 치밀하고 자기보다 전통적으로 덜 유리화된 중간 소지 | 부분 유리화, 비교적 낮은 기공 | 대략 3–10% 구간(BIIa/BIIb 등)에 걸칠 수 있으나 1:1 표준 용어 아님 | 국내 유통에서 사용 빈도가 낮고 자기질과 혼용; 과거식 재질명으로 취급 |
| **vitrified tile / 자기질(현장)** | 소성 중 액상 형성·유리화로 치밀해진 소지라는 재료 개념 | 낮은 기공, 높은 치밀도 | 국내 `자기질`이 ISO BIa인지 BIb인지 시험값으로 확인 | 한국에서 포세린과 동의어처럼 쓰이기도 하나 `자기질=항상 E≤0.5%`로 자동 변환 금지 |
| **stone/quarry/cement/glass** | 천연석·시멘트계·유리는 세라믹 소지와 다른 재료군 | 별도 재료·시험체계 | `visual_effect=stone-look`과 `actual_material=stone` 분리 | “대리석타일”이 천연대리석인지 대리석무늬 포세린인지 반드시 확인 |

### 2.2 ISO 13006 / EN 14411 흡수율 그룹 매트릭스

`E = 건조질량 대비 포화 후 증가질량(%)`, 시험은 ISO 10545-3에 따른다.

| 성형 | Ia | Ib | IIa | IIb | III |
|---|---:|---:|---:|---:|---:|
| **A 압출** | E ≤ 0.5% | 0.5 < E ≤ 3% | 3 < E ≤ 6% | 6 < E ≤ 10% | E > 10% |
| **B 건식 프레스** | E ≤ 0.5% | 0.5 < E ≤ 3% | 3 < E ≤ 6% | 6 < E ≤ 10% | E > 10% |
| **C 기타 성형** | 제품 규격/선언 확인 |  |  |  |  |

**경계값 규칙:** 0.5%는 Ia, 3%는 Ib, 6%는 IIa, 10%는 IIb이다. 평균값만 보고 그룹을 정하면 안 되고 해당 부속서가 요구하는 개별값/허용차도 원문으로 확인한다. [S1, A]

### 2.3 한국 데이터 정규화 권고

```text
material_raw = "자기질 포세린 폴리싱"
material_family = ceramic
body_term_raw = 자기질
porcelain_claim = true
forming_method = unknown            # B로 추정하지 않음
iso13006_group = unknown            # 성적서 전에는 미확정
water_absorption_pct = unknown
surface_finish = polished
edge = unknown                      # 폴리싱으로 rectified 추정 금지
claim_evidence = seller_spec
```

KS L 1001의 공식 상세 페이지는 명칭을 **“도자기질 타일”**로 두고 적용범위를 도자기질 타일로 설명하며, ISO 13006:1998과의 부합 수준을 **NEQ(동일하지 않음)**로 표시한다. 따라서 한국 KS 명칭을 최신 ISO 13006:2018과 자동 동치화하지 않는다. [S14, A]

## 3. 제조공정: 공정축을 표면·성능축과 분리하기

### 3.1 표준 공정 흐름

```text
원료 수입·검사
→ 파쇄/배합/계량
→ [습식 분쇄→슬립 저장·체질·제철→분무건조] 또는 [건식 분쇄→분급→가습·과립화]
→ 분말 숙성·공급
→ 프레스(B) 또는 압출(A) 성형
→ 건조
→ 바탕/engobe·유약·디지털 장식(제품 설계에 따라 생략/순서 변화)
→ 1회 또는 2회 이상 소성
→ 선별(치수 caliber·색 shade·평탄도·결함)
→ 필요 시 폴리싱/호닝·래티파잉/모서리 가공·표면처리
→ 최종 검사·포장
```

SACMI는 타일 소지 준비 라인에서 원료 계량, 배치/연속 **습식 밀**, 슬립·유약 설비를 별도 공정으로 제시한다. 이는 `습식=물에 젖어 쓰는 타일`이 아니라 원료 준비 방식임을 보여준다. [S15, B]

### 3.2 습식법과 건식법 비교

| 항목 | 습식 원료조제(wet route) | 건식 원료조제(dry route) |
|---|---|---|
| 핵심 | 물과 함께 볼밀링해 슬립을 만들고 균질화·체질 후 분무건조하여 프레스 과립 제조 | 원료를 낮은 수분 상태로 분쇄·분급하고 필요한 수분을 더해 직접 과립/조립 |
| 장점 경향 | 미세 혼합·균질화, 색/조성 제어, 프레스 충전성이 좋은 구형 과립 | 공정수·건조에너지·폐수 부담을 줄일 잠재력, 공정 단축 |
| 관리 위험 | 분무건조 에너지, 물·슬립 관리, 침전/점도·해교제 관리 | 과립 유동성·수분 균일성·분진, 원료 변동에 대한 민감도; 제품별 적용성 검증 필요 |
| 결과에 대한 금지 추론 | 습식이라고 고급/포세린/강함을 자동 보장하지 않음 | 건식이라고 도기질/무유/저급을 뜻하지 않음 |
| 데이터 필드 | `body_preparation=wet_milled_spray_dried` | `body_preparation=dry_ground_granulated` |

### 3.3 개별 공정 용어

| 공정/용어 | 정확한 뜻 | 성능과의 관계 | 혼동 금지 |
|---|---|---|---|
| **프레스 성형** | 과립을 금형에 충전해 일축 압축; ISO 그룹 B의 일반적 방식 | 충전·수분·압력 불균일은 밀도차, 뒤틀림, 균열 원인 | `dry-pressed`는 소지 준비가 반드시 완전 건식이라는 뜻이 아님. 습식분쇄→분무건조 분말도 건식 프레스함 |
| **압출 성형** | 가소성 반죽을 다이로 밀어 연속 단면을 만들고 절단; ISO 그룹 A | 후면 리브·긴 형상 등에 유리, 압출방향 수축 관리 | 압출=석기질/외장용으로 자동 판정 금지 |
| **건조** | 성형체 자유수를 제어 제거 | 건조 구배가 균열·휨·층분리 유발 | 건조와 소성은 다른 단계 |
| **소성** | 가열로 유기물 제거, 탈수산, 소결·액상형성·유리화, 냉각 | 흡수율·수축·강도·열응력을 지배 | 소성온도 하나로 품질 비교 금지; 조성·시간·분위기·곡선이 함께 작용 |
| **단소성(monocottura)** | 소지와 유약을 함께 본소성 | 현대 바닥/포세린에서 흔함 | 단소성=무유·통바디 아님 |
| **복소성/bicottura** | 소지를 먼저 소성한 뒤 유약/장식을 다시 소성 | 장식·유약 설계 자유도; 다공질 벽타일에서 흔함 | 2회 소성=무조건 고급/강함 아님 |
| **engobe/바탕유** | 소지와 상유약 사이의 백색도·접합·가스/색 차폐층 | 유약 결함과 외관 안정에 기여 | 상유약(glaze)과 동일층으로 단순화 금지 |
| **유약(glaze)** | 소성 시 유리질 표면층을 형성하는 조성 | 오염·화학·마모 성능과 외관을 바꾸나 균열(crazing) 가능 | 유약=유광 아님; 무광 유약도 있음. 무유=무광도 아님 |
| **디지털 프린팅** | 잉크젯으로 잉크/효과재를 비접촉 토출해 무늬·효과 구현 | 다면 디자인·정합성 향상; 최종 성능은 잉크만이 아니라 유약·소성·표면구조의 시스템 결과 | 프린트로 보이는 대리석/목재는 실제 재료가 아님. 사진만으로 디지털/로토콜러 판별 불가 |
| **폴리싱** | 소성 후 연마재로 표면을 기계 절삭해 광택·평활도를 높임 | 마찰·오염·미세기공 노출이 변할 수 있어 완제품 시험 필요 | 유광(glossy glaze)과 다른 공정. `폴리싱 포세린`, `유약 폴리싱`, `라파토`를 분리 |
| **라파토/lappato** | 부분·반광 연마를 뜻하는 브랜드/업계 용어 | 광택과 무광이 혼합될 수 있음 | fully polished, satin, honed와 자동 동치화 금지 |
| **래티파이드/rectified** | 소성 후 가장자리를 절삭/연삭해 직각도·작업치수를 더 엄격히 맞춘 edge treatment | 좁고 균일한 줄눈 설계에 도움 | 무줄눈 시공 허가가 아님; 포세린·폴리싱·대형과 동의어 아님. 이미지로 확정 불가 |
| **caliber / shade** | 소성 후 실제 치수군 / 색조군 선별 코드 | 혼용 시 줄눈 불균일·색 차 | nominal size와 work size, lot/shade/caliber를 분리 저장 |

프레스·장식 설비가 별도 공정군으로 제공되는 제조사 기술 페이지도 이 축 분리를 뒷받침한다. [S16, B] [S17, B]

## 4. 네 규격 체계의 역할 비교

| 체계 | 주 역할 | 분류/시험 연결 | 실무 주의 |
|---|---|---|---|
| **ISO 13006:2018** | 세라믹 타일의 정의·성형/흡수율 분류·특성·표시 | ISO 10545 시험법을 호출하고 A/B + 흡수율 그룹별 부속서 요구치 제시 | 제품 규격. 시험방법 자체는 ISO 10545 각 부를 확인 |
| **EN 14411:2016** | 유럽의 정의·분류·특성, 성능의 불변성 평가·검증(AVCP), 표시 | 기술 분류는 ISO 13006과 매우 유사하고 EN ISO 10545 계열 사용 | EU/UK 시장의 DoP/CE·UKCA 맥락과 해당 국가 채택판을 확인. ISO 인증 문구와 CE 선언은 같은 것이 아님 |
| **ISO 10545 시리즈** | 샘플링, 치수, 흡수율, 파괴, 마모, 동결, 화학 등 개별 시험방법 | 결과값을 생산; 합격기준은 ISO 13006/EN 14411의 해당 그룹 또는 계약 규격이 부여 | 시험했다는 사실과 합격했다는 사실을 분리. 정확한 part/연도/조건 기록 |
| **ANSI A137.1** | 미국 세라믹 타일 제품 규격·정의·성능 | ASTM C373(흡수), C648(파괴), C1027/C1243(마모), C650(화학), C1026(동결) 및 DCOF AcuTest 등 미국 시험체계 사용 | ISO 수치와 시험법이 다른 항목을 직접 등치하지 않음. 발주서에 판본(예: A137.1-2022) 명시 |

**중요:** `EN 14411 = ISO 13006`이라고만 저장하지 않는다. 기술 내용은 정렬되어도 판본, 규제 부속서, 표시·적합성 경로가 다르다. [S1, A] [S9, A] [S10, A]

## 5. 시험별 비교와 판독법

### 5.1 핵심 시험 표

| 성능 | ISO/EN 시험 | 측정 원리·결과 | ANSI A137.1 계열 | 판독/혼동금지 |
|---|---|---|---|---|
| **흡수율 E** | ISO 10545-3:2018 | 건조 질량과 규정 방식으로 포화한 질량의 증가율. 겉보기 기공률·상대밀도·벌크밀도도 다룸 | ASTM C373 | ISO 그룹 분류의 핵심이지만 내오염·미끄럼·강도 전체를 대신하지 않음. 포화법/판본이 다른 결과를 무비판 합치지 않음 [S2, A] |
| **파괴강도 breaking strength** | ISO 10545-4:2019 | 지지 롤러 위 시편에 중앙 하중을 주어 파괴 시 하중에서 **breaking strength(N)** 산출 | ASTM C648의 breaking strength | N은 제품 두께·폭/스팬 영향을 받는 하중 지표. MPa와 같은 값이 아님 [S3, A] |
| **파괴계수 MOR** | ISO 10545-4:2019 | 파괴하중과 시편 치수로 계산한 굽힘응력 **N/mm²=MPa** | ANSI 품목별 요구는 해당 표 확인 | MOR과 breaking strength를 모두 보되 상호 바꿔 쓰지 않음. 현장 바탕·접착·공극에 따른 파손은 별도 시스템 문제 |
| **깊이 마모(무유)** | ISO 10545-6:2010 | 회전 디스크와 연마재로 마모홈을 내고 제거 체적(mm³) 평가 | ASTM C1243 등 제품유형별 | **무유 바닥타일용**. 값이 작을수록 제거량이 적다. 유약 타일 PEI class와 비교 금지 [S4, A] |
| **표면 마모(유약)** | ISO 10545-7:1996 | 규정 연마하중 단계 후 관찰되는 유약 표면 변화로 class 분류 | ASTM C1027 | 흔히 “PEI 0–5”라 부르지만 이는 유약 표면 마모 분류이지 Mohs 경도, 무유 깊이마모, 미끄럼 등급이 아님 [S5, A] |
| **내화학성** | ISO 10545-13:2016 | 상온에서 가정용 약품·수영장염류와 산/알칼리에 노출 후 시각/표면 변화를 등급화 | ASTM C650 | `chemical resistant` 단일 yes/no 대신 **시험액 농도·유약 여부·등급** 저장. 내오염(ISO 10545-14)과 다름 [S6, A] |
| **동결융해** | ISO 10545-12:1995 + Corr.1 | 물 존재하 동결 조건용 타일을 규정 사이클에 노출한 뒤 손상 판정 | ASTM C1026 | 낮은 E는 유리한 지표지만 **E≤0.5만으로 동결 시험 합격을 창작하지 않음**. 완제품 시험/제조사 선언 확인 [S7, A] |
| **미끄럼** | EN 14411은 용도에 따라 특성 선언; 보행면 시험은 유럽에서 EN 16165 방법군 등이 사용됨 | shod ramp R, barefoot A/B/C, pendulum PTV 등 **방법별 별도 결과** | ANSI A137.1의 DCOF AcuTest; 일반적으로 수분 노출이 예상되는 평탄한 실내 보행면에 wet DCOF ≥ 0.42 기준이 널리 적용 | 0.42는 모든 장소의 “안전 보증”이 아니며 경사로·샤워바닥·기름/오염·신발·유지관리·줄눈을 포괄하지 않음. R↔DCOF↔PTV 환산 금지 [S10/S11/S12, A/B] |

### 5.2 ISO 10545 파트 번호 체크

- Part 3 = 흡수율/기공률/밀도 [S2]
- Part 4 = 파괴계수 및 파괴강도 [S3]
- Part 6 = **무유** 타일 깊이마모 [S4]
- Part 7 = **유약** 타일 표면마모 [S5]
- Part 12 = 동결저항 [S7]
- Part 13 = 내화학성 [S6]
- Part 14 = 내오염성(내화학성과 별도) [S8]

**특별 혼동금지:** ISO 공식 카탈로그의 10545 시리즈 목록에는 2026-07-27 확인 시 **Part 17이 게시되어 있지 않다**(Part 16 다음은 Part 18). 따라서 `ISO 10545-17 미끄럼 시험 성적`이라는 문구는 표준 번호·발행기관·초안 여부를 원문으로 재검증한다. 유럽 보행면 미끄럼은 EN 16165, 미국 세라믹 타일은 ANSI A137.1 DCOF를 각각 확인한다. [S19, A] [S12, A]

## 6. ANSI A137.1과 ISO/EN 사이의 주요 비동치

| 주장 | 올바른 처리 |
|---|---|
| “포세린은 둘 다 0.5% 이하니까 완전히 같은 인증” | 분류 경계가 같아도 시험법(ISO 10545-3 vs ASTM C373), 샘플링, 제품 정의, 인증/표시 체계가 다르다. 원 시험법과 인증 주체를 기록 |
| “ANSI compliant = 모든 용도 가능” | 제품 품목별 요구와 적용환경을 확인. 특히 DCOF 0.42는 제한된 사용조건의 선택 기준이지 보편 안전선이 아님 |
| “ISO 10545 시험성적서 = ISO 13006 인증” | 시험방법 수행과 제품규격 적합 판정/제3자 인증은 다름 |
| “CE = 품질등급” | CE/DoP는 해당 규제 체계에서 선언된 성능·적합성 절차의 표시이며, 판매자가 임의로 말하는 품질 서열이 아님 |
| “R11이면 DCOF 0.42 이상” | 시험기, 오염매체, 신발, 경사/평면, 판정량이 달라 환산식 없음. 각 원시험 결과를 병렬 저장 |

## 8. 혼동금지 규칙(에이전트 하드 룰)

1. **상위/하위:** 모든 포세린은 세라믹이지만 모든 세라믹은 포세린이 아니다.
2. **명칭/시험:** 포세린·자기질·도기질이라는 상품명보다 성형법과 시험 흡수율을 우선한다.
3. **흡수율/용도:** 낮은 흡수율은 동결·치밀도 판단에 유용하지만 바닥용, 외부용, 수영장용, 내화학, 미끄럼 안전을 단독 보장하지 않는다.
4. **공정/표면:** 습식·건식은 원료 준비, 프레스·압출은 성형, 유약/무유는 표면층, 폴리싱은 후가공이다.
5. **광택/연마:** glossy glaze와 polished를 합치지 않는다. matte, honed, satin, lappato도 raw 용어를 보존한다.
6. **텍스처/미끄럼:** rough/structured/embossed는 시각·촉각 형상; DCOF/R/PTV는 시험 성능이다.
7. **마모 시험:** 유약 ISO 10545-7 class와 무유 ISO 10545-6 mm³를 비교하거나 환산하지 않는다.
8. **PEI/Mohs:** PEI 마모등급은 Mohs 긁힘 경도가 아니다.
9. **하중/응력:** breaking strength(N)와 MOR(MPa)를 같은 “강도” 숫자로 정렬하지 않는다.
10. **내화학/내오염:** ISO 10545-13과 -14를 구분한다.
11. **동결:** `porcelain` 또는 `E≤0.5`만 보고 frost pass를 생성하지 않는다.
12. **미끄럼:** dry COF와 wet DCOF, DCOF와 R/PTV/A-B-C를 혼합·환산하지 않는다.
13. **래티파이드:** rectified는 edge/size 가공이지 무줄눈, 무칼리버, 완전 직선, 포세린의 동의어가 아니다.
14. **디지털 무늬/재료:** marble-look·wood-look·terrazzo-look를 실제 석재·목재·테라조 재료로 저장하지 않는다.
15. **KS/ISO:** KS L 1001은 공식 페이지상 ISO 13006:1998 NEQ다. 최신 ISO 13006과 자동 동치화하지 않는다.
16. **시험/인증:** `tested to`, `meets`, `certified`, `CE/DoP`를 서로 다른 상태값으로 저장한다.
17. **판본:** 표준번호만 저장하지 말고 연도·개정/정오표를 포함한다.
18. **평균/개별:** 평균만 통과해도 개별 최소 요구가 있으면 부적합일 수 있다.

## 9. 이미지로 판별할 수 없는 항목

### 9.1 이미지 단독으로 **확정 불가**

- 세라믹/포세린/도기질/자기질/석기질 및 실제 광물·소지 조성
- ISO 13006 그룹(AIa, BIa, BIII 등), 성형법(프레스/압출), 습식/건식 원료조제
- 흡수율, 겉보기 기공률, 밀도, 파괴강도, MOR
- 유약 여부(특히 얇은 무광 유약), 통바디/컬러바디, 소성 횟수·온도
- ISO 10545-6/-7 마모값/등급, Mohs, 스크래치 성능
- 내화학, 내오염, 동결융해, 열충격, crazing 성능
- DCOF, R, PTV, barefoot class 및 실제 젖은 바닥 안전성
- rectified 여부와 치수 허용차, nominal/work size, 두께
- 디지털 프린트인지 로토콜러/스크린인지, 잉크·유약 적층 순서
- 로트, shade, caliber, 제조국·공장, 인증 진위
- 실러/나노처리/오염방지처리의 존재와 내구성

### 9.2 이미지에서 가능한 것은 **관찰 후보**뿐

- 색군, 명도, 무늬 계열(대리석풍/목재풍/테라조풍), 방향성
- 보이는 광택 경향(조명·렌더·후처리 영향 표시)
- 눈에 보이는 요철/엠보 후보, 모서리 외관 후보
- 단일면/다중면/시공사진/렌더라는 이미지 역할

### 9.3 이미지 판독 출력 예시

```text
관찰: 회색 저대비 시멘트풍 무늬, 무광으로 보임, 직사각 대형 형상 후보
확정 불가: 포세린 여부, 600×1200 실제 규격, rectified, R11/DCOF, 동결저항
필요 증거: SKU 라벨 + 제조사 TDS + ISO/ASTM 시험성적서 + 박스 lot/shade/caliber
```

## 10. 자재GO 에이전트 권장 판정 로직

1. 원문 표현을 `raw`에 보존한다.
2. 재료, ISO 그룹, 흡수율, 성형, 원료조제, 표면층, 광택, 질감, edge, 용도, 시험성능을 별도 필드로 분해한다.
3. `porcelain`은 (a) 제조사 명시 + (b) E≤0.5의 시험/표준 근거가 있을 때 `verified`; 판매명만 있으면 `claimed`.
4. 외부/동결부는 E만으로 승인하지 않고 frost 결과, 시공시스템, 기후/배수 조건을 요구한다.
5. 젖은 바닥은 `시험법+조건+값/등급+공간`이 없으면 `slip_performance=unknown`.
6. 표준 간 결과는 환산하지 않고 병렬 저장한다.
7. 이미지 입력만 있으면 성능/재료를 abstain하고 카탈로그 후보 검색으로 전환한다.
8. 최종 답변에는 항상 `근거 URL, 문서/필드, 판본, 근거등급, 확인일`을 붙인다.

### 링크 접근성 메모

- ISO/ANSI 본문은 유료이고 일부 사이트는 자동접근 시 403/봇 차단을 반환했다. 공식 URL·제목·공개 초록을 확인하고, 상세 합격수치는 원문 구매 후 재검증하도록 표시했다.
- S11/S13은 업계 해설·인증 보조 출처이므로 ANSI 수치가 충돌하면 **구매한 A137.1 해당 판본**이 우선한다.
- 제조사 설비자료는 공정 존재와 장비 흐름의 근거이지, 특정 타일 SKU의 실제 공정을 증명하지 않는다.
