# 자재GO 타일 전문 지식베이스

조사 기준일: 2026-07-27

## 목적

공개 제조사·판매처의 실제 상품 상세페이지와 기술자료를 근거로 타일의 종류, 외관 효과, 패턴, 마감, 표면 질감과 이미지 판별 한계를 구조화한다. 페이지 본문과 이미지는 복제하지 않고 요약·정규화 규칙·출처 URL만 보존한다.

## 핵심 운영 원칙

1. 외관 효과, 실제 재료, 마감, 표면 질감, 미끄럼 성능을 서로 다른 필드로 관리한다.
2. 이미지에서는 색상·패턴·모티프·가시적 요철을 관찰하되 실제 재료와 물성을 추정하지 않는다.
3. 사용자가 선택한 규격과 마감은 후보 생성 단계의 절대필터이며 자동으로 완화하지 않는다.
4. 정면 제품컷, 여러 face 배열, 디테일, 시공컷, 합성컷, 렌더를 이미지 단위로 구분한다.
5. 출처·원문 필드·수집 시점·근거 등급을 보존한다.
6. 확실한 근거가 없으면 `unknown` 또는 `abstain`을 반환한다.
7. 이미지 검색은 정확 SKU 단정과 Top-5 유사상품 추천의 신뢰도를 분리한다.
