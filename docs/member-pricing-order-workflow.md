# 회원 등급·가격·주문 운영 기준

## 회원 등급

- 신규 사업자 회원의 기본 등급은 `B등급`입니다.
- 관리자는 주문관리 화면에서 승인 상태와 `A등급`, `B등급`, `C등급`을 함께 지정합니다.
- 고객 상품 API는 로그인 회원에게 배정된 등급의 단가 한 개만 반환합니다.
- 고객 응답에는 원가, 공급처, 내부 브랜드, 다른 등급 단가를 포함하지 않습니다.

## 가격 선택 순서

등급 단가는 상품 원가를 기준으로 다음과 같이 계산하고 100원 단위로 올림합니다.

- A등급: 원가 + 25%
- B등급: 원가 + 30%
- C등급: 원가 + 50%

원가가 없거나 0원인 상품은 자동 계산에서 제외하며, 관리자가 원가를 확인한 뒤 다시 적용합니다.

가격 선택 순서:

1. 회원 등급에 해당하는 `gradeAPrice`, `gradeBPrice`, `gradeCPrice`
2. 등급 단가가 없고 원가가 있으면 위 등급 정책으로 실시간 계산
3. 유효한 단가가 없으면 주문 접수를 막고 관리자 문의를 안내

주문 금액은 브라우저가 전송한 값을 신뢰하지 않고 서버가 상품 DB와 회원 등급으로 다시 계산합니다.

관리자는 상품관리 화면에서 현재 필터에 해당하는 상품을 대상으로 등급 단가를 미리보기 한 뒤 일괄 적용합니다. 실제 적용 전에는 상품 DB 백업을 자동 생성합니다.

## 주문 접수

회원은 장바구니에서 연락처, 현장 배송지, 희망 배송일, 요청사항을 입력합니다. 접수 직후 상태는 항상 `접수대기`이며 고객이 임의 상태를 지정할 수 없습니다.

관리자 처리 상태:

`접수대기 → 주문확인 → 결제대기 → 결제완료 → 재고확인 → 견적확정 → 출고준비 → 배차대기 → 배송중 → 배송완료 → 완료`

필요하면 관리자가 `취소`로 변경합니다.

## 샘플 신청

샘플 신청은 주문과 분리해 관리하며 관리자 주문관리 화면의 `샘플 신청 처리`에서 접수, 준비, 발송, 배송 상태와 운송장 정보를 저장합니다.

## 운영 점검

- 회원 승인 시 등급을 반드시 확인합니다.
- 주문 접수 시 주문 당시 등급, 배송지, 희망일을 확인합니다.
- 가격이 없는 상품은 임의 금액으로 주문 처리하지 않습니다.
- 배송 완료 후 상태를 갱신해 회원 마이페이지와 관리자 화면을 일치시킵니다.
