# 자재GO 모바일 앱 1차 구조

## 목표

기존 웹과 모바일 앱이 같은 상품, 회원, 장바구니, 주문 데이터를 사용하면서 앱 설치 파일은 가볍게 유지한다.

## 구성

| 영역 | 역할 |
| --- | --- |
| Railway | 웹 화면과 자재GO API 제공 |
| Supabase | 회원, 상품, 주문 데이터 저장 |
| PWA | 홈 화면 설치, 앱 아이콘, 오프라인 안내 |
| Capacitor | Android/iOS 앱 컨테이너와 네이티브 기능 연결 |
| CDN/원격 이미지 | 상품 이미지를 앱 설치 파일에서 분리 |

## 데이터 원칙

1. 관리자 비밀번호, Supabase 서비스 키, OpenAI 키는 앱에 포함하지 않는다.
2. 고객용 API에는 내부 브랜드, 공급처, 원가 필드를 반환하지 않는다.
3. API와 로그인 통신은 `https://jajaego.com`을 사용한다.
4. 상품 DB 전체를 오프라인 캐시에 저장하지 않는다.
5. 서비스 워커는 앱 셸 파일만 캐시하고 `/api/` 응답은 캐시하지 않는다.

## 단계별 출시

### 1단계

- PWA 설치 지원
- Android 프로젝트 생성
- 모바일 뒤로가기와 딥링크 기반
- 앱 아이콘과 시작 화면

### 2단계

- 시스템 브라우저 소셜 로그인
- 사진 촬영 및 업로드
- 앱 푸시 알림
- 주문 및 승인 상태 알림
- 공유와 파일 다운로드

### 3단계

- Android 내부 테스트 및 Google Play 비공개 테스트
- iOS TestFlight
- 스토어 심사 자료 및 개인정보 신고

## 출시 차단 조건

다음 항목이 끝나기 전에는 공개 스토어에 제출하지 않는다.

1. 소셜 로그인 콜백 실기기 검증
2. 계정삭제와 개인정보처리방침 연결
3. 앱 강제 종료와 네트워크 장애 복구 검증
4. 로그인 고객에게 내부 브랜드, 공급처, 원가가 노출되지 않는지 검증
5. 카메라와 사진 권한 안내 문구 검수
